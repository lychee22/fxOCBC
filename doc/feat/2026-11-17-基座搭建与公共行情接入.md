## 需求描述

按 doc/规划文档.md v0.3 的阶段范围，完成第一个原子交付单元：**基座（main app）+ 公共行情最小版（app-market）**，跑通完整接入协议（注册 / 生命周期 / 路由 / 通信 / 鉴权链路）。基座参考 qiankun 官方 examples/main 改造。

## 范围

- In scope：
  - pnpm monorepo：`apps/main`（基座，Vite + React18 + qiankun）、`apps/market`（行情子应用，webpack5 UMD）、`packages/sdk`（契约类型/通信/工具）；
  - 基座七项职责骨架：布局、mock 登录、路由分发、子应用注册与生命周期、全局状态总线、权限守卫、监控兜底；
  - app-market：UMD 生命周期导出、行情 mock 推送（节流）、独立运行模式；
  - 文档：接入协议（arch）、选型决策（adr）、验收清单（test）。
- Out of scope：
  - 其余四个业务子应用（transfer / pmfx / wealth / loan）；
  - 生产 SSO / 网关对接（mock，接口已预留）；
  - 配置中心动态注册、灰度发布。

## 验收标准

- [x] 基座可登录（mock），未登录访问受保护路由回到 /login；
- [x] 访问 /market 基座按需加载子应用，loading → 渲染行情页；
- [x] 子应用 mount/unmount 无残留（定时器/订阅显式清理）；
- [x] 子应用脱离基座可独立运行（http://localhost:7101 直开）；
- [x] 行情数据经事件总线（@one-bank/sdk bus）广播，供后续子应用订阅；
- [x] 子应用加载失败不白屏（基座 qiankun addErrorCapture + ErrorBoundary）；
- [x] typecheck / build 全部通过。
