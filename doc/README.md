# doc/ 文档中心 · 使用说明

本目录是 one-bank 项目唯一的文档中心，覆盖需求、缺陷、原型、方案、决策、发布与验收。**仓库中不再保留其他文档目录。**

| 目录 | 定位 | 记什么 | 命名规则 |
| --- | --- | --- | --- |
| `/`（本级） | 基线 | `规划文档.md`：需求 + 架构 + 模块 + 阶段范围 + 非功能基线 | 固定名 |
| `feat/` | 迭代需求（**做什么**） | 每个迭代需求一个文件，含状态字段 | `YYYY-MM-DD-标题.md` |
| `debug/` | 缺陷记录 | 复现步骤、严重级别、状态 | `YYYY-MM-DD-标题.md` |
| `proto/` | 原型图与样式记录 | 原型图、样式约定（规范见 [proto/README.md](proto/README.md)） | `YYYY-MM-DD-标题` + 图片文件 |
| `arch/` | 技术方案与接口契约（**怎么做**） | 方案设计、模块间接口约定、时序图、外部依赖对接结论（SSO/网关/行情源） | `主题.md`（如 `子应用接入协议.md`） |
| `adr/` | 选型决策（**为什么**） | 每次选型/重大决策一个文件 | `NNN-标题.md`（如 `001-微前端框架选型.md`） |
| `changelog/` | 发布/版本记录 | 每次发布一个条目 | `vX.Y.Z-YYYY-MM-DD.md` |
| `test/` | 验收清单 | 每个原子单元一份验收清单 | `原子N-名称.md` |

**feat 与 adr 分工（防混用）**：feat 记"做什么"（需求），adr 记"为什么这样做"（选型）。例："接入 wujie"写进 feat；"为什么不用 qiankun"写进 adr。

---

## 通用规范

### 文件命名

- 一律 `小写英文/数字 + 连字符 + 中文标题`，**禁止空格**（Windows + git 兼容）；
- 日期统一 `YYYY-MM-DD`，时区 Asia/Shanghai。

### 状态字段（feat / debug 通用）

```
状态：草稿 | 进行中 | 已完成 | 已取消
```

## 文件模板

### feat 模板

```markdown
# YYYY-MM-DD-标题

状态：草稿
优先级：P0 | P1 | P2 | P3
关联：adr/NNN-xxx、arch/xxx（如有）

## 需求描述
（做什么、为什么现在做）

## 范围
- In scope：
- Out of scope：

## 验收标准
- [ ] （可检查的条目）

## 备注 / 风险
```

### debug 模板

```markdown
# YYYY-MM-DD-标题

状态：待修复 | 修复中 | 已修复 | 无法复现 | 关闭
严重级别：S0（阻断）| S1（严重）| S2（一般）| S3（轻微）
环境：local | dev | test | production

## 现象
## 复现步骤
1.
## 期望 vs 实际
## 根因
## 修复方案与验证
```

### adr 模板

```markdown
# NNN-标题

日期：YYYY-MM-DD
状态：提议 | 已采纳 | 已废弃（被 NNN 取代）

## 背景
（为什么需要做这个决策）

## 备选方案对比
| 方案 | 优点 | 缺点 |

## 结论
（选了什么，核心理由 1–3 条）

## 后果与约束
（该决策带来的限制、后续必须遵守的事项）
```

### test 验收清单模板

```markdown
# 原子N-名称 验收清单

对应 feat：../feat/YYYY-MM-DD-xxx.md

- [ ] 功能项 1
- [ ] 生命周期：mount/unmount 无残留副作用（定时器、监听器）
- [ ] 路由：深链直达、前进/后退正常
- [ ] 样式：无全局泄漏
- [ ] 鉴权：401 回到基座登录
- [ ] 兜底：加载失败不白屏
- [ ] 独立运行：脱离基座可本地开发
```

## 术语表

| 术语 | 定义 |
| --- | --- |
| 基座（Shell / Main App） | 微前端主应用，提供布局、路由分发、子应用生命周期管理与公共能力 |
| 子应用（Sub App） | 按业务域拆分的独立前端应用，遵循接入契约，可独立开发/构建/部署 |
| 接入契约 | 基座与子应用的约定：生命周期导出、路由前缀、通信接口、环境标识 |
| 原子单元 | 最小可运行、可独立验证的交付组合，如"基座 + 公共行情最小版" |
| 公共行情（app-market） | 汇率/金价/净值行情的统一接入与分发服务，向其他子应用提供数据 |
| 购汇 / 结汇 | 购汇：用人民币购买外汇；结汇：将外汇兑换回人民币 |
| 净值 | 财富管理产品的单位份额价格，用于产品申购/赎回计价 |
| SSO | 单点登录（Single Sign-On），行内统一认证平台 |
