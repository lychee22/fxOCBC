# proto/ 原型图与样式记录

记录每个迭代需求的原型图与样式约定，与 feat 文件一一对应。

## 目录约定

- 原型图：`YYYY-MM-DD-标题/` 子目录，内含图片 + 说明；
- 样式约定：`YYYY-MM-DD-标题.md`，记录该需求的布局、间距、主题色等约定。

## 文件模板

```markdown
# YYYY-MM-DD-标题

关联 feat：../feat/YYYY-MM-DD-xxx.md

## 原型图
![原型-首页](2026-11-17-基座首页/首页.png)
<!-- 每张图配一句：图示内容 / 关键交互 -->

## 样式约定
- 布局：顶部导航 64px + 侧边菜单 220px（可收起）；
- 主题色：以基座 CSS Variables 下发，子应用只消费不覆盖；
- 间距/字号：遵循 ui-kit 默认 token，例外须在此登记。
```

## 通用样式基线

- 子应用样式必须加作用域前缀（如 `.app-market-`），禁止裸写全局选择器；
- 主题变量（颜色/字号/圆角）由基座统一下发，子应用不得覆盖；
- 图片文件与 md 同名放置，引用相对路径，禁止外链图片。
