# 子应用接入协议

日期：2026-11-17
状态：已采纳（基线 v1，随原子单元迭代修订）

## 1. 总则

- 微前端框架：qiankun（选型见 adr/001）；基座 = Main App，业务方 = 子应用。
- 子应用**独立开发、独立构建、独立部署**；跨应用协作只经 `@one-bank/sdk` 或基座提供的能力，禁止直接引用彼此内部代码。

## 2. 工程与构建约定

| 项 | 约定 |
| --- | --- |
| 技术栈 | 不限（React/Vue/jQuery 均可），入口需按 §3 导出生命周期 |
| 打包格式 | UMD，`library.name` 必须等于注册名（如 `one-bank-market`） |
| devServer | 允许跨域：`Access-Control-Allow-Origin: *`；historyApiFallback 开启 |
| publicPath | 独立运行 `/`；被基座加载时以 `__INJECTED_PUBLIC_PATH_BY_QIANKUN__` 修正（webpack 应用） |
| 端口分配 | main=7000，market=7101，transfer=7102，pmfx=7103，wealth=7104，loan=7105 |
| 依赖共享 | `@one-bank/sdk` 为契约内依赖，经 pnpm workspace `workspace:*` 引用 |

## 3. 生命周期契约

子应用入口必须导出：

```ts
export async function bootstrap(): Promise<void>;
export async function mount(props: MicroAppProps): Promise<void>;  // 渲染到 props.container ?? 自身根节点
export async function unmount(): Promise<void>;                    // 清理定时器/监听/订阅，不留副作用
```

- `mount` 中的 DOM 挂载点：基座传入 `props.container`（qiankun 场景）或应用自身 HTML 根节点（独立运行场景）；
- `unmount` 必须：卸载组件树、clearInterval/clearTimeout、事件总线反注册、关闭长连接。

## 4. 路由契约

- 每个子应用占用唯一路由前缀（见规划文档 §2）：`/market`、`/transfer`、`/pmfx`、`/wealth`、`/loan`；
- 子应用内部路由需带 basename（`props.basename` = 注册前缀），并保证深链直达、前进/后退正常；
- 基座负责把前缀分发给对应子应用；子应用不得修改全局历史栈以外的路由。

## 5. 通信契约（@one-bank/sdk）

- `bus`：全局事件总线（发布/订阅）。子应用在 mount 订阅、unmount 反注册；
  - 现有事件：`market:rate-updated`（行情推送，含节流建议 ≤500ms）、`session:changed`（登录态）；
- `initGlobalState`（qiankun）：基座持有 `user`、`theme`，子应用经 `onGlobalStateChange` 同步；
- 工具函数：`formatAmount` / `formatRate`（金额与汇率展示统一走公共格式化，规划文档非功能基线）。

## 6. 鉴权契约

- 会话由基座统一管理；子应用从 `props.session` 读取当前用户；
- 子应用内任何 401/会话失效 → 触发 `bus.emit('session:changed', null)` 或跳转基座登录（由基座监听处理）；
- 子应用不得自行存储/刷新 Token。

## 7. 注册流程

1. 子应用按本协议完成改造（UMD + 生命周期 + 前缀）；
2. 在 `apps/main/src/micro/apps.ts` 的 `MICRO_APPS` 注册表中登记 `name / entry / activeRule / props.basename`；
3. 按 test/原子N 验收清单逐项验收后合入。

## 8. 环境标识

- 子应用经 `window.__POWERED_BY_QIANKUN__` 判断运行环境；独立运行必须可用（本地开发不依赖基座）；
- `@one-bank/sdk` 暴露 `APP_ENV`（dev/test/prod），构建注入。
