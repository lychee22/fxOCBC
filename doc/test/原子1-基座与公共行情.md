# 原子1-基座与公共行情 验收清单

对应 feat：../feat/2026-11-17-基座搭建与公共行情接入.md

## 启动方式

```bash
pnpm install
pnpm dev          # 同时启动 market(7101) 与 main(7000)
# 或分开：pnpm dev:market && pnpm dev:main
```

## 清单

- [x] 功能项：基座 7000 可登录（mock），登录后进入首页布局
- [x] 功能项：访问 /market 动态加载子应用，行情页展示 USD/CNY 与金价并定时刷新
- [x] 生命周期：mount/unmount 无残留副作用（定时器、监听器）—— market/src/main.tsx 显式清理
- [x] 路由：深链直达（直接打开 http://localhost:7000/market 登录后可进）、前进/后退正常
- [x] 样式：无全局泄漏（基座 shell- 前缀、子应用 market- 前缀；未开启全局样式隔离）
- [x] 鉴权：未登录访问受保护路由 → 回到基座 /login，登录后回原路径
- [x] 兜底：子应用加载失败不白屏（基座 ErrorBoundary + qiankun 错误捕获；加载中/失败有 UI 提示）
- [x] 独立运行：脱离基座可本地开发（http://localhost:7101 直开自动自行挂载）
